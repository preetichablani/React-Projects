React Projects

A collection of React.js assignments developed during my learning journey. These projects demonstrate the practical implementation of React fundamentals, reusable components, state management, form handling, and modern frontend development practices.

---

📖 Repository Overview

This repository contains three React assignments built using **React.js** and **Vite**. Each project is designed to strengthen core React concepts while following clean code and responsive UI practices.

---

📂 Projects Included

🔹 Assignment 1 – Trending Products
A responsive product showcase application built with reusable React components.

**Key Features**
- Component-based architecture
- Reusable Product Cards
- Props implementation
- Responsive user interface
- Clean and structured layout

---

🔹 Assignment 2 – Todo List
A task management application that allows users to organize daily activities efficiently.

**Key Features**
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Dynamic state management using React Hooks
- User-friendly interface

---

🔹 Assignment 3 – Workshop Registration Form
A responsive registration form with validation and controlled components.

**Key Features**
- Form validation
- Controlled inputs using React Hooks
- Radio button selection
- Responsive design
- Clean and modern UI

---
